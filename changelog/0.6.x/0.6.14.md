# 0.6.14 — 2026-05-25

## Fixed

- **`openalex_analyze_trends`** — non-boolean `group_by` fields now send `cursor=*` on the first request to enable pagination; previously, `next_cursor` was never returned. Boolean fields (`is_retracted`, `is_oa`, `has_orcid`, etc.) continue without cursor — they only produce two groups and upstream rejects cursor on them. ([#23](https://github.com/cyanheads/openalex-mcp-server/issues/23))
- **`openalex_literature_review`** — step 4 now directs `openalex_get_citation_graph` with `direction "cites"` for subsequent work and `direction "cited_by"` for foundational work; previous description inverted the filter semantics. ([#24](https://github.com/cyanheads/openalex-mcp-server/issues/24))
- **`openalex_literature_review`** `scope` — changed from `.default('narrow')` to `.optional()` so `prompts/list` advertises `required: false`; `generate` resolves `args.scope ?? 'narrow'` internally. ([#25](https://github.com/cyanheads/openalex-mcp-server/issues/25))
