# 0.6.10 — 2026-05-16

Picks up [`@cyanheads/mcp-ts-core` 0.9.0 + 0.9.1](https://github.com/cyanheads/mcp-ts-core/blob/main/CHANGELOG.md). 0.9.0 was framework-breaking (Workers `nodejs_compat` boot fix, cross-vendor JSON Schema portability lint family, build-time-only lint gate), but the changes here are additive — none of this server's Zod schemas use the now-flagged `format` values (`z.url()`, `z.cuid()`, etc.).

## Added

- **`instructions`** on `createApp()` ([cyanheads/mcp-ts-core#91](https://github.com/cyanheads/mcp-ts-core/issues/91)) — server-level orientation included on every `initialize` response. Spec-compliant clients forward it to the model as session-level system context, so the "resolve names before filtering" rule and the entity-type catalog no longer have to be duplicated into every tool description.
