# 0.6.16 — 2026-05-30

## Added

- **`enrichment` block** on `openalex_search_entities`, `openalex_analyze_trends`, `openalex_get_citation_graph`, and `openalex_resolve_name` — query/filter echoes, true result totals, and empty-result recovery guidance now surface in a typed `enrichment` block that reaches both the `structuredContent` JSON and the `content[]` markdown trailer via `ctx.enrich()`.
  - `search_entities`: `echo`, `totalCount`, and optional `notice` on empty results.
  - `analyze_trends`: `echo`, `entityTotal`, and optional `notice` on zero groups.
  - `get_citation_graph`: `echo`, `totalEdges`, and optional `notice` on empty traversals.
  - `resolve_name`: optional `notice` on no-match results.
- **`AGENTS.md`** added to the npm `files[]` list so agent-protocol docs ship with the package.

## Changed

- **`openalex_search_entities` / `openalex_analyze_trends` / `openalex_get_citation_graph`** — `output.meta.echo` removed; the query echo now appears in `enrichment.echo` (value and semantics unchanged; only the structuredContent key changed).
- **`@cyanheads/mcp-ts-core`** ^0.9.13 → ^0.9.16.
- **`format` script** split into `format` (safe) and `format:unsafe` (--unsafe flag); `format` no longer passes `--unsafe`.
- **`skills/devcheck/SKILL.md`** removed — content merged into `api-linter` skill in the framework.
