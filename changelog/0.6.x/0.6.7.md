# 0.6.7 — 2026-05-03

Pure maintenance release. Five framework versions of `@cyanheads/mcp-ts-core` (0.8.8 → 0.8.12) — all additive (DataCanvas Tier-3 primitive, `disabledTool()` wrapper, mutability-bucket annotations, `RequestContext` widening, SQL-gate hardening). None of the new surfaces apply to this server: there's no canvas usage, no feature-flagged tools to disable, and the existing `readOnlyHint`/`idempotentHint` annotations already place all three tools in the `read` mutability bucket. Audited the current `OpenAlexService` HTTP-error pattern (`fetchWithTimeout` + `httpStatusToErrorCode` + factory throw with `data.reason`) against the `httpErrorFromResponse` helper introduced earlier in 0.8.x — both helpers operate at different layers (transport vs. plain-fetch classification) and the current pattern is correct, not suboptimal.
