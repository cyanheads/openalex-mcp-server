# 0.6.19 — 2026-06-02

## Changed

- **HTTP transport** per-request logs and traces now carry fresh request + trace/span IDs instead of the frozen boot context — fixes log correlation for concurrent requests. (framework: `@cyanheads/mcp-ts-core` 0.9.21)
- **`fetchWithTimeout`** strips query-string secrets (e.g. `?api_key=`) from error messages and logs before surfacing them. (framework)
- **`withRetry`** fails fast on non-retryable errors rather than exhausting retry attempts; `ctx.fail` auto-populates the `retryable` flag on the error payload. (framework)

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.16 → ^0.9.21
