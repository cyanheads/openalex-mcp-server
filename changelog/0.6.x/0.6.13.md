# 0.6.13 — 2026-05-23

## Added

- **`manifest.json`** — MCPB bundle descriptor for one-click Claude Desktop install; `bun run bundle` produces `.mcpb` via `@anthropic-ai/mcpb pack`.
- **`.mcpbignore`** — excludes non-bundle files from the `.mcpb` artifact.
- **`lint:packaging` script** — verifies env var name parity between `server.json` and `manifest.json`; runs as part of `devcheck`.
- **`bundle` script** — `bun run build && npx -y @anthropic-ai/mcpb pack . dist/@cyanheads/openalex-mcp-server.mcpb`.
- **Install badges** (README) — one-click install links for Claude Desktop (`.mcpb`), Cursor, and VS Code.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.1 → ^0.9.6`.
- **`zod`** `^4.4.3` — added as a direct dependency (re-exported by mcp-ts-core; direct pin avoids range divergence).
- **`OPENALEX_API_KEY`** — corrected from required to optional across `server.json`, `manifest.json`, README, and AGENTS.md; anonymous access works without it, polite pool requires an email.
- **`devcheck`** — now includes `lint:packaging` and `list-skills` steps.
- **Skills synced** to current `@cyanheads/mcp-ts-core` versions: `maintenance`, `field-test`, `polish-docs-meta`, `release-and-publish`.
