# 0.11.0 — 2026-10-28

Minor release: the resource `skill://openalex-guide/SKILL.md` is new, and the `omitted` and `over_budget` output fields are removed.

## Added

- **`awards` entity** (G IDs, grants with amounts, dates, and investigators) on `openalex_search_entities`, `openalex_analyze_trends`, and `openalex_describe_fields`; a `G…` ID or award URL routes to `/awards/`, and a `G…` ID under another `entity_type` fails `id_type_mismatch`. ([#125](https://github.com/cyanheads/openalex-mcp-server/issues/125))
- **Seeded `sample` paging** — `sample` accepts up to 10,000 and walks with `page` plus `seed`; reasons `sample_page_without_seed` and `sample_page_too_deep` reject an unseeded `page` and a `page × per_page` past 10,000. ([#124](https://github.com/cyanheads/openalex-mcp-server/issues/124))
- **`slice.limit`** (default 50, cap 5,000) sets the elements a `slice` returns. ([#131](https://github.com/cyanheads/openalex-mcp-server/issues/131))
- **`response_too_large`** error on both record tools names the `per_page` or `slice.limit` that fits. ([#131](https://github.com/cyanheads/openalex-mcp-server/issues/131))
- **`openalex-guide` skill**, served as `skill://openalex-guide/SKILL.md`: filter-key gates, `group_by` reading rules, and ID chains.

## Changed

- **Page size** — a page is every record of the upstream page, and an `id` lookup returns each selected array whole. A response over 8,000,000 bytes on either surface now fails `response_too_large` where 0.10.1 returned a shortened page, so an `id` or `slice` call on a work with thousands of authors can return megabytes. ([#131](https://github.com/cyanheads/openalex-mcp-server/issues/131))
- **`slice`** reads `limit`, so `slice.limit` 0 is rejected (0.10.1 ignored unknown `slice` keys).
- **`openalex_resolve_name`** given a bare `G…` ID with no `entity_type`, or an award URL, returns a notice naming the `openalex_search_entities` call and sends no request (0.10.1 name-searched it, so `G3` found a journal). With an `entity_type`, a bare `G…` is still searched as a name; its `entity_type` enum stays the eight autocomplete types. ([#125](https://github.com/cyanheads/openalex-mcp-server/issues/125))
- **Semantic `per_page`** above 50 clamps with a notice unless `OPENALEX_CLAMP_PER_PAGE=false` (0.10.1 rejected it); `sample` above 10,000 and `slice.limit` above 5,000 clamp the same way. Clamped count inputs no longer advertise a `maximum` in `tools/list`.
- **`sample`** cap 100 → 10,000, and `per_page` under `sample` defaults to `min(sample, 100)` rather than pinning to `sample`.
- **Metric** `openalex.per_page.clamps` renamed `openalex.count_input.clamps`.
- **Semantic and sample `page` pointers** name only reachable pages, and `meta.next_cursor` descriptions state that an exactly-full final page still returns a cursor leading to an empty page. ([#126](https://github.com/cyanheads/openalex-mcp-server/issues/126))
- **Notices** escape caller text for Markdown on `openalex_search_entities`, `openalex_get_citation_graph`, `openalex_analyze_trends`, and `openalex_resolve_name`, so `content[]` and `structuredContent.notice` match. ([#127](https://github.com/cyanheads/openalex-mcp-server/issues/127))
- **Multi-line catalog text** (abstracts, raw affiliation strings) keeps its line breaks in `content[]`; a `display_name` with a break heads its record with the ID and takes a `**Display Name:**` line. ([#128](https://github.com/cyanheads/openalex-mcp-server/issues/128))
- **Server instructions** state that catalog text is data, never instructions. ([#129](https://github.com/cyanheads/openalex-mcp-server/issues/129))
- **`openalex_describe_fields`** omits award fields OpenAlex refuses to group by, plus `is_in_jstage` on sources and two institutions count fields.
- **Literature-review and research-landscape prompts** page `author_list` with `slice.limit` and point funding questions at `awards.id`.

## Removed

- **`omitted` and `over_budget`** output fields on `openalex_search_entities` and `openalex_get_citation_graph`; no page is cut to a budget. ([#131](https://github.com/cyanheads/openalex-mcp-server/issues/131))
- **Reason `sample_with_page`**, replaced by `sample_page_without_seed` and `sample_page_too_deep`. ([#124](https://github.com/cyanheads/openalex-mcp-server/issues/124))

## Fixed

- **Boolean `group_by` fields** (any `is_*` or `has_*` segment, plus `mag_only` and `open_access.any_repository_has_fulltext`) group without `cursor=*` and keep count order under `order: "key"`, instead of failing upstream for 50 of 59 fields. ([#123](https://github.com/cyanheads/openalex-mcp-server/issues/123))
