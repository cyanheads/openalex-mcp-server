# 0.7.13 — 2026-09-13

## Changed

- **Plugin configuration** now exposes the OpenAlex API key, mailto, base URL, and log level through Claude Code user settings and Codex environment forwarding; the MCPB manifest wires the same options into its server environment.
- **HTTP links** no longer duplicate the trailing slash in `MCP_PUBLIC_URL`, and the landing-page curl example uses a compatible initialization handshake (framework fixes from 0.12.8 and 0.12.9).
- **Environment parsing** treats empty strings and whole-value `${…}` placeholders as unset, so optional OpenAlex settings remain absent and defaulted settings use their schema defaults.
- **Framework skills and maintenance tooling** now use the `framework-skills/` layout and current scaffold checks, packaging validation, issue forms, and contributor guidance; development requires Bun 1.4.0 or newer.
