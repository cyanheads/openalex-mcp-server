# 0.7.12 — 2026-09-08

## Fixed

- **`normalizeId()` gains a PubMed Central URL branch** (#67) — `https://pmc.ncbi.nlm.nih.gov/articles/PMC…/` and the legacy `https://www.ncbi.nlm.nih.gov/pmc/articles/PMC…/` now normalize to `pmcid:PMC…` like the bare form, instead of being forwarded verbatim as a work ID, across `openalex_search_entities` (`id`), `openalex_resolve_name` (`query`), and `openalex_get_citation_graph` (`seed_id`).
- **A `pmcid:`-scheme 404 now carries a PMCID-specific recovery hint** (#67) — OpenAlex indexes no PMCIDs, so the shared 404 mapping and the `resolve_name` miss notice now say to convert to a PMID or DOI instead of the generic "verify the ID format" text, which could never help a well-formed PMCID.
- Tool descriptions and README bullets no longer present PMCID as an identifier that resolves — it's recognized, bare or as a PubMed Central URL, but resolves nothing.
