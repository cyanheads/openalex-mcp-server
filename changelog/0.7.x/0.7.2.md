# 0.7.2 — 2026-06-20

Framework-maintenance only — no source or tool-surface changes.

## Changed

- **`devcheck.config.json`** — added `packaging.pluginManifests: true`, enabling `lint:packaging` check 10 over `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` (non-empty descriptions, unscoped machine name in display fields, full scoped name in the `npx -y` install arg). ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))
- **`scripts/check-dependency-specifiers.ts`** — new devcheck step (`Dependency Specifiers`, flag `--no-dep-specifiers`) rejecting floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` dependency sections and `bun.lock`'s `workspaces` map. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **`scripts/lint-packaging.ts`** — gained the plugin-marketplace manifest validation (check 10) gated by the new `packaging.pluginManifests` flag. ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))
- **Fresh-scaffold devcheck guards** — `scripts/devcheck.ts` skips the git-dependent checks (TODOs/FIXMEs, Tracked Secrets, Framework Antipatterns) via a shared `isGitRepo()` guard; `scripts/build-changelog.ts --check` exits cleanly with no per-version files; `scripts/check-framework-antipatterns.ts` self-guards outside a repo; `scripts/check-skill-versions.ts` skips a `SKILL.md` deleted from the worktree. ([cyanheads/mcp-ts-core#237](https://github.com/cyanheads/mcp-ts-core/issues/237), [#242](https://github.com/cyanheads/mcp-ts-core/issues/242), [#243](https://github.com/cyanheads/mcp-ts-core/issues/243))
- **Skills sync** — `add-tool`, `api-auth`, `api-canvas`, `api-config`, `api-context`, `api-errors`, `api-services` (+ `graph`/`speech` references), `api-telemetry`, `field-test`, `git-wrapup`, `orchestrations`, `polish-docs-meta`, `report-issue-local`, `tool-defs-analysis` re-synced from mcp-ts-core 0.10.7–0.10.9.
