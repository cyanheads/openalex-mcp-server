# 0.7.9 — 2026-08-22

## Changed

- **MCP protocol support** adopts `@cyanheads/mcp-ts-core` 0.12: undeclared tool input keys are rejected, and advertised tool output schemas include the structured error envelope.
- **OpenAlex request context** now passes the handler context directly through retries and HTTP calls.
- **Container builds** use Bun 1.4 with native builder-platform selection and omit optional peer tiers from the production image.
- **Developer guidance and community health** now cover the SDK v2 input model, current protocol behavior, contribution expectations, and private security reporting.

## Fixed

- **OpenAlex error messages** retain a truncation notice when a bounded upstream error body remains valid JSON after head-tail elision.
