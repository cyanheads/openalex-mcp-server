# 0.7.0 — 2026-06-08

## Fixed

- **`openalex_analyze_trends`** — the page-truncation notice is now gated on sort order. In `order: "key"` mode, the tool emits a key-ascending pagination notice keyed off `next_cursor` instead of the count-descending "top N by count" wording, whose count-bound claims were false on key-ordered pages. The count-bound notice is unchanged for the default count-descending mode. ([#41](https://github.com/cyanheads/openalex-mcp-server/issues/41))

## Notes

0.7.0 is a minor version bump. The `openalex_describe_fields` tool shipped in 0.6.21 — a new tool falls under semver's minor convention; the 0.6.x designation was a patch-series overstep. No API or behavior changes beyond the fix above.
