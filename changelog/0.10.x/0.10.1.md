# 0.10.1 — 2026-10-25

## Changed

- **Query echo** — the enrichment trailer's `Query:` line renders as an inline code span, so a copied query reads back with no backslash escapes (mcp-ts-core 0.13.18, [#785](https://github.com/cyanheads/mcp-ts-core/issues/785)).
- **Error text in `content[]`** — the `Error:` message, `Recovery:` hint, and reason escape Markdown metacharacters with backslashes; `structuredContent` keeps the original strings (mcp-ts-core 0.13.16, [#760](https://github.com/cyanheads/mcp-ts-core/issues/760)).
- **Framework configuration** — a non-integer or out-of-range count or timer variable stops startup with a message naming the variable, e.g. `MCP_HTTP_PORT (mcpHttpPort): Invalid input: expected int, received number` (mcp-ts-core 0.13.16).
- **Response budget** — `trailerTextBytes` counts the echo's code-span fence and the `> ` prefix on every line of a notice, so the 64,000-byte per-surface budget measures what `content[]` carries under the new rendering.
- **Packaging** — root Agent Plugins `plugin.json` and `mcp.json` (a stdio entry running `npx -y @cyanheads/openalex-mcp-server`), root-anchored `.mcpbignore` lines for source, tests, docs, changelog, plugin manifests, and agent docs, and the framework's bundle cleaner dropping its own build-only files (`changelog/`, `config/`, `scripts/`, `templates/`, `CLAUDE.md`, `AGENTS.md`) from the `.mcpb` (mcp-ts-core 0.13.18).
- **`skills/`** — the Dockerfile creates and copies an empty `skills/` directory and `package.json` `files` lists it, for template alignment; this server publishes no skills.
- **Framework skills and scripts** re-synced to mcp-ts-core 0.13.18, adding the `add-skill` skill; `CLAUDE.md` and `AGENTS.md` follow (skills section, MCP SDK `^2.4.0`).
- **README** — getting started condensed to hosted and local installs, with Docker and source-build detail under Running the server.
- **`.env.example`** — the `MCP_SESSION_MODE` comment is rewritten; the value stays `stateless`.
- **Issue forms** — the bug report takes one Environment table in place of separate version, runtime, transport, and OS fields; the feature request's `breaking-change` label no longer says it requires a major bump.
- **`bunfig.toml`** — `minimumReleaseAge` 3 days → 1 day.
